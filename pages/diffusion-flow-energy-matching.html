1. 统一视角：所有方法都在回答同样的三个问题

生成建模的任务是从数据分布 \( p_{\text{data}} \) 里采样。高维空间直接建密度极难——归一化常数算不出来，直接 MCMC 又混合得太慢。现代方法的共识做法是绕开密度，去构造一条路：

共同骨架
\[ \underbrace{p_0 = \mathcal{N}(0, I)}_{\text{好采样}} \;\xrightarrow{\;\;\text{学一个场，沿它走}\;\;}\; \underbrace{p_1 = p_{\text{data}}}_{\text{想要的}} \]

「场」的意思是：空间里每一点都告诉你下一步往哪儿挪。采样就退化成解一个（随机或确定的）微分方程。各方法的区别可以完全压缩进三个问题：

  • 路径怎么定？DDPM/DDIM 用「逐步加高斯噪声」隐式定义；Flow Matching 直接手工指定（最常用是直线插值），Rectified Flow 更进一步，把「路径够不够直」变成可迭代校正的目标；Energy Matching 则让路径由标量势的梯度生成。
  • 网络学什么？DDPM 学噪声 \( \varepsilon_\theta \)（等价于分数 \( \nabla_x \log p_t \)）；Flow Matching 学速度场 \( v_\theta \)；Energy Matching 学一个标量函数 \( V_\theta \)，场是它的梯度。
  • 怎么走完？DDPM 走随机 SDE（步数多）；DDIM 走确定 ODE（可跳步）；Flow Matching 走更直的 ODE（步数更少）；Energy Matching 先传输、后用 Langevin 落进玻尔兹曼平衡。

U-Net / DiT / JiT 属于另一根轴——它们回答「谁来计算这个场」，而不是「学什么、怎么走」。DiT 第一版用的就是 DDPM 的目标函数，只是把骨干换成了 Transformer。这根轴单独放在第 10 节讲，先把它从脑子里摘出去，前九节会清爽很多。

2. DDPM：加噪是已知的，学去噪就够了

Ho et al. 2020 · arXiv 2006.11239

DDPM（Denoising Diffusion Probabilistic Model）的出发点朴素得近乎笨拙：既然从数据到噪声这条路我们完全知道怎么走（不断加高斯噪声），那就只学反过来那一步。

2.1 前向过程：一条写死的马尔可夫链

取一列很小的方差 \( \beta_1 \lt \beta_2 \lt \cdots \lt \beta_T \)（典型 \( T=1000 \)，\( \beta \) 从 1e-4 线性到 0.02），定义

前向（无参数，不需要学）
\[ q(x_t \mid x_{t-1}) = \mathcal{N}\!\big(x_t;\ \sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I \big) \]

每步都做「缩一点 + 加一点噪声」。缩放系数取 \( \sqrt{1-\beta_t} \) 不是随手写的：它保证方差不爆炸，\( t\to T \) 时 \( x_T \) 收敛到标准高斯。记 \( \alpha_t = 1-\beta_t \)、\( \bar\alpha_t = \prod_{s\le t}\alpha_s \)，高斯的可加性给出关键的闭式跳步公式：

任意时刻一步到位
\[ \begin{gathered} q(x_t\mid x_0) = \mathcal{N}\!\big(x_t;\ \sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I\big) \\[6pt] \Longleftrightarrow\quad x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon,\qquad \varepsilon\sim\mathcal{N}(0,I) \end{gathered} \]

这条公式是整个方法能训起来的技术核心：训练时不需要真的走 1000 步，随机抽一个 \( t \)、抽一个 \( \varepsilon \)，一行代码就造出 \( x_t \)。这叫 simulation-free 训练。

2.2 反向过程：学一个高斯的均值

当 \( \beta_t \) 足够小，反向条件 \( q(x_{t-1}\mid x_t) \) 也近似是高斯，于是用网络参数化：

\[ p_\theta(x_{t-1}\mid x_t) = \mathcal{N}\!\big(x_{t-1};\ \mu_\theta(x_t,t),\ \sigma_t^2 I\big) \]

训练目标来自变分下界（ELBO）。把 ELBO 拆开，主体是一串 KL：

\[ \begin{aligned} \mathcal{L} = \mathbb{E}_q\Big[\ & \underbrace{D_{\mathrm{KL}}\big(q(x_T|x_0)\,\|\,p(x_T)\big)}_{\text{常数，无参数}} \\[4pt] &+ \sum_{t\gt 1}\underbrace{D_{\mathrm{KL}}\big(q(x_{t-1}|x_t,x_0)\,\|\,p_\theta(x_{t-1}|x_t)\big)}_{\text{真正要优化的}}\ -\ \log p_\theta(x_0|x_1)\Big] \end{aligned} \]

好在 以 \( x_0 \) 为条件的反向后验有解析解（贝叶斯 + 高斯共轭）：

\[ \begin{gathered} q(x_{t-1}\mid x_t, x_0) = \mathcal{N}\big(\tilde\mu_t(x_t,x_0),\ \tilde\beta_t I\big) \\[8pt] \tilde\mu_t = \frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1-\bar\alpha_t}\,x_0 + \frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}\,x_t, \qquad \tilde\beta_t = \frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}\beta_t \end{gathered} \]

两个高斯之间的 KL 就是均值差的平方。再用跳步公式把 \( x_0 \) 换成 \( \varepsilon \)（\( x_0 = (x_t - \sqrt{1-\bar\alpha_t}\varepsilon)/\sqrt{\bar\alpha_t} \)），均值的最优形式变成：

ε-参数化
\[ \mu_\theta(x_t,t) = \frac{1}{\sqrt{\alpha_t}}\Big(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\varepsilon_\theta(x_t,t)\Big) \]

代回去，再丢掉每项前面的加权系数（Ho 等人发现不加权反而效果更好——等价于给高噪声段更大权重），得到那个著名的、朴素到不像变分推断的损失：

DDPM 的全部训练目标
\[ \mathcal{L}_{\text{simple}} = \mathbb{E}_{t\sim\mathcal{U}[1,T],\ x_0\sim p_{\text{data}},\ \varepsilon\sim\mathcal{N}(0,I)} \Big\| \varepsilon - \varepsilon_\theta\big(\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\varepsilon,\ t\big) \Big\|^2 \]
📌
ε 就是分数（score）

由高斯密度求导可得 \( \nabla_{x}\log q(x_t\mid x_0) = -\dfrac{\varepsilon}{\sqrt{1-\bar\alpha_t}} \)。所以「预测噪声」与「预测分数 \( \nabla_x\log p_t(x) \)」只差一个已知系数——DDPM 和 score-based 模型是同一件事的两种记号。后来常用的 \( x_0 \)-预测、\( v \)-预测也都是这个量的线性重参数化。

2.3 训练与采样：十行伪代码

# ---- 训练 ----
for x0 in dataloader:
    t   = randint(1, T)                       # 每个样本独立抽一个时刻
    eps = randn_like(x0)
    xt  = sqrt(abar[t]) * x0 + sqrt(1 - abar[t]) * eps   # 闭式跳步，不用模拟
    loss = mse(eps, eps_theta(xt, t))
    loss.backward(); opt.step()

# ---- 采样（祖先采样 / ancestral sampling）----
x = randn(shape)
for t in reversed(range(1, T + 1)):
    z = randn_like(x) if t > 1 else 0
    x = (x - (1 - a[t]) / sqrt(1 - abar[t]) * eps_theta(x, t)) / sqrt(a[t]) + sigma[t] * z
⚠️
代价

反向链与前向链步数绑死：训练时定了 \( T=1000 \)，采样就得跑 1000 次网络前向。生成一张图要几十秒。而且每步注入的随机性使得步子不能迈大——大步走会累积可见的误差。

3. DDIM：训练锁的只是边缘分布

Song, Meng & Ermon 2021 · arXiv 2010.02502

DDIM（Denoising Diffusion Implicit Model）的洞察极其漂亮，值得单独拎出来一句话说清：

\( \mathcal{L}_{\text{simple}} \) 只用到了边缘分布 \( q(x_t\mid x_0) \)，从头到尾没用到前向过程是马尔可夫的。

换句话说，训练好的 \( \varepsilon_\theta \) 并不属于某一条特定的链，它属于所有共享同样边缘的过程构成的一整族。于是可以构造一族非马尔可夫前向过程，用一个自由参数 \( \sigma_t \) 索引：

同边缘的非马尔可夫族
\[ q_\sigma(x_{t-1}\mid x_t, x_0) = \mathcal{N}\Big(\sqrt{\bar\alpha_{t-1}}\,x_0 + \sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\cdot\tfrac{x_t-\sqrt{\bar\alpha_t}x_0}{\sqrt{1-\bar\alpha_t}},\ \sigma_t^2 I\Big) \]

可以验证：无论 \( \sigma_t \) 取什么，它诱导出的 \( q_\sigma(x_t\mid x_0) \) 都还是那个 \( \mathcal{N}(\sqrt{\bar\alpha_t}x_0, (1-\bar\alpha_t)I) \)。所以旧模型直接拿来用，一个字都不用重训。

3.1 采样公式：预测 → 重新加噪

把 \( x_0 \) 换成网络给出的估计 \( \hat{x}_0 \)，得到 DDIM 的更新式。它有非常直白的三段结构：

DDIM 一步
\[ \hat{x}_0^{(t)} = \frac{x_t - \sqrt{1-\bar\alpha_t}\,\varepsilon_\theta(x_t,t)}{\sqrt{\bar\alpha_t}} \] \[ x_{t-1} = \underbrace{\sqrt{\bar\alpha_{t-1}}\,\hat{x}_0^{(t)}}_{\text{① 指向预测的干净图}} + \underbrace{\sqrt{1-\bar\alpha_{t-1}-\sigma_t^2}\,\varepsilon_\theta(x_t,t)}_{\text{② 沿原噪声方向退回去}} + \underbrace{\sigma_t z}_{\text{③ 新注入的随机性}} \]

第 ③ 项的强度是个可调旋钮。取

\[ \sigma_t(\eta) = \eta\sqrt{\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t}}\sqrt{1-\frac{\bar\alpha_t}{\bar\alpha_{t-1}}} \]
  • \( \eta = 1 \) → 完全还原成 DDPM 的祖先采样。
  • \( \eta = 0 \) → 第 ③ 项消失，整个采样过程完全确定：给定 \( x_T \)，输出唯一。这就是狭义的 DDIM。

3.2 为什么能跳步

因为没有了随机性，更新式不再依赖「相邻」这个概念——它只依赖 \( \bar\alpha \) 的两个值。于是可以任选一个递减子序列 \( \tau_1 \lt \tau_2 \lt \cdots \lt \tau_S \subset \{1,\dots,T\} \)（比如 1000 步里等间隔取 50 个），把公式里的 \( t, t-1 \) 换成 \( \tau_i, \tau_{i-1} \) 直接用。网络调用次数从 1000 降到 20–50，质量损失很小。

3.3 确定性带来的三个副产品

  • ODE 结构。令 \( \eta=0 \)，做重参数化 \( \bar{x} = x/\sqrt{\bar\alpha} \)、\( \lambda = \sqrt{1-\bar\alpha}/\sqrt{\bar\alpha} \)，更新式恰好是 \( \mathrm{d}\bar{x} = \varepsilon_\theta\,\mathrm{d}\lambda \) 的欧拉离散。所以 DDIM 不是启发式加速，而是某个 ODE 的一阶求解器——DPM-Solver、DEIS 这些后续工作就是换更高阶的求解器，把步数再压到 10 步级。
  • 可逆（DDIM inversion）。ODE 反着积分能把一张真实图片映回它对应的 \( x_T \)，改一改再正向积回来，就得到可控编辑。这是 prompt-to-prompt、图像编辑一大类方法的地基。
  • 隐空间有语义。\( x_T \) 到样本是双射，对两个 \( x_T \) 做球面插值，生成结果也平滑过渡；DDPM 由于每步都注入新噪声，做不到这点。
💡
一句话

DDPM 决定了学什么，DDIM 说明了怎么走可以另说。这是「训练目标」与「采样器」正式分家的时刻，此后二者独立演进。

4. 中场：连续极限把上面两者归位

4.1 先把 DDPM 写成一条 SDE

Song 等人 2021 年（arXiv 2011.13456）指出，\( T\to\infty \) 时 DDPM 的前向链就是一条随机微分方程（VP-SDE）：

一般形式 / DDPM 的取值
\[ \mathrm{d}x = \underbrace{f(x,t)}_{\text{漂移}}\,\mathrm{d}t + \underbrace{g(t)}_{\text{扩散}}\,\mathrm{d}w \qquad\Longrightarrow\qquad \mathrm{d}x = -\tfrac12\beta(t)\,x\,\mathrm{d}t + \sqrt{\beta(t)}\,\mathrm{d}w \]

它的时间反演也是 SDE，且需要的唯一未知量就是分数 \( \nabla_x\log p_t(x) \)。更关键的是，存在一条确定性的常微分方程，它在每个时刻的边缘分布与反向 SDE 完全相同：

概率流 ODE（Probability Flow ODE）
\[ \frac{\mathrm{d}x}{\mathrm{d}t} = f(x,t) - \tfrac12 g(t)^2\,\nabla_x\log p_t(x) \]

4.2 逐项拆开

符号是什么DDPM 里取什么
\( \mathrm{d}x/\mathrm{d}t \)一个样本点的速度——这一步该往哪儿挪—
\( f(x,t) \)漂移项，确定性的那部分拉扯\( -\tfrac12\beta(t)x \)，即「往原点缩」
\( g(t) \)扩散系数，每单位时间注入多少噪声\( \sqrt{\beta(t)} \)
\( \nabla_x\log p_t(x) \)分数，指向密度更高的方向。全式唯一的未知量网络学的就是它：\( \approx -\varepsilon_\theta/\sqrt{1-\bar\alpha_t} \)（§2.2）

4.3 那个 ½ 是从 Fokker–Planck 掉出来的

它不是「近似地把噪声减半」，而是一步精确改写。SDE 的密度演化服从 Fokker–Planck 方程：

\[ \frac{\partial p_t}{\partial t} = -\nabla\!\cdot\!\big(f\,p_t\big) + \tfrac12 g^2\,\Delta p_t \]

用恒等式 \( \nabla p = p\,\nabla\log p \)，把那个二阶的扩散项改写成一阶的散度形式：

\[ \tfrac12 g^2\,\Delta p_t \;=\; \nabla\!\cdot\!\Big(\tfrac12 g^2\,\nabla p_t\Big) \;=\; \nabla\!\cdot\!\Big(\tfrac12 g^2\,p_t\,\nabla\log p_t\Big) \]

代回去，两项合并成一个散度：

\[ \frac{\partial p_t}{\partial t} = -\nabla\!\cdot\!\Big[\underbrace{\Big(f-\tfrac12 g^2\nabla\log p_t\Big)}_{\displaystyle v(x,t)}\ p_t\Big] \]

这已经是纯粹的连续性方程 \( \partial_t p = -\nabla\!\cdot\!(vp) \)——描述一群粒子以速度场 \( v \) 被搬运时密度怎么变，里面没有任何随机性。而 \( v \) 正是那条 ODE 的右边。所以概率流 ODE 不是「扔掉噪声的近似」，而是把扩散项精确翻译成了一个搬运项。那个 \( \tfrac12 \) 直接来自 Itô 公式里的 \( \tfrac12 g^2 \)。

📌
和反向 SDE 对照，系数差一半

反向 SDE 是 \( \mathrm{d}x = \big[f - g^2\nabla_x\log p_t\big]\mathrm{d}t + g\,\mathrm{d}\bar w \)，分数前面是 \( g^2 \)；概率流 ODE 是 \( \tfrac12 g^2 \)，但没有噪声项。多出来的那半份确定性漂移，恰好换掉了整个随机项。§3.1 里 DDIM 的 \( \eta \) 旋钮，走的就是这两端之间的连续插值。

4.4 直觉：散开这件事，不一定要靠随机

噪声让点云散开。但「散开」也可以完全确定地做到——让每个粒子沿着密度梯度的反方向挪一点，云团照样以一模一样的方式摊平。单条轨迹截然不同（SDE 抖、ODE 光滑且互不相交），但每个时刻的直方图重合。

4.5 代进 DDPM 看看长什么样

把 \( f=-\tfrac12\beta(t)x \)、\( g=\sqrt{\beta(t)} \) 代入，再把分数换成网络输出：

\[ \frac{\mathrm{d}x}{\mathrm{d}t} = -\tfrac12\beta(t)\Big[x + \nabla_x\log p_t(x)\Big] \;\approx\; -\tfrac12\beta(t)\Big[x - \frac{\varepsilon_\theta(x,t)}{\sqrt{1-\bar\alpha_t}}\Big] \]

右边只剩已知量和网络的一次前向——这就是一个可以直接丢给任意 ODE 求解器的东西。DDIM 是它的一阶欧拉离散，DPM-Solver / DEIS 则是换用更高阶的求解器。

4.6 这个视角一落地，两件事立刻显然

  1. 采样的随机性是可选项，不是必需品——同样的边缘可以用确定的流走出来。
  2. 既然最终需要的只是「一个能把 \( \mathcal{N}(0,I) \) 输运到 \( p_{\text{data}} \) 的 ODE」，那为什么非得走「加高斯噪声」这条特定的路？

第二个问题就是 Flow Matching 的起点。

5. Flow Matching：路径可以自己指定，而且最好是直的

Lipman et al. 2023 · arXiv 2210.02747

5.1 老问题：CNF 训不动

连续归一化流（CNF）本来就把生成写成 ODE：\( \frac{\mathrm{d}x}{\mathrm{d}t} = v_\theta(x,t) \)，从 \( p_0 \) 推到 \( p_1 \)。理论完美，但传统训法是最大似然，要在训练循环里反复解 ODE 并算散度（simulation-based），慢且不稳，一直没能 scale。

5.2 新思路与它的障碍

Flow Matching 的想法直白：如果我们事先指定一条概率路径 \( p_t \) 及其对应的向量场 \( u_t \)，那训练就退化成一个回归：

\[ \mathcal{L}_{\text{FM}}(\theta) = \mathbb{E}_{t\sim\mathcal{U}[0,1],\ x\sim p_t}\big\| v_\theta(x,t) - u_t(x) \big\|^2 \]

障碍在于：能生成「混合分布」\( p_t \) 的边缘场 \( u_t(x) \) 是个积分，写不出来也算不了。

5.3 破局：条件 Flow Matching（CFM）

解法与 DDPM 用的是同一招——把目标条件化到单个数据点上。给每个数据样本 \( x_1 \) 配一条条件路径 \( p_t(x\mid x_1) \) 和条件场 \( u_t(x\mid x_1) \)（这两者可以随手设计成闭式的），边缘就是它们的混合：\( p_t(x) = \int p_t(x\mid x_1)q(x_1)\mathrm{d}x_1 \)。核心定理是：

CFM 定理：两个损失的梯度相同
\[ \nabla_\theta \mathcal{L}_{\text{FM}} = \nabla_\theta \mathcal{L}_{\text{CFM}},\qquad \mathcal{L}_{\text{CFM}} = \mathbb{E}_{t,\ x_1\sim q,\ x\sim p_t(\cdot\mid x_1)}\big\| v_\theta(x,t) - u_t(x\mid x_1) \big\|^2 \]

直觉是最小二乘的老性质：同一个 \( (x,t) \) 会被来自不同 \( x_1 \) 的条件目标反复拉扯，平方损失的最优解自动是条件期望，而这个条件期望恰好就是边缘场 \( u_t(x) \)。你回归一个算得出的量，收敛到一个算不出的量。

5.4 选路径：高斯族与它的两个特例

取条件路径为高斯 \( p_t(x\mid x_1)=\mathcal{N}(\mu_t(x_1),\sigma_t(x_1)^2 I) \)，则唯一对应的条件场有闭式：

\[ u_t(x\mid x_1) = \frac{\sigma_t'(x_1)}{\sigma_t(x_1)}\big(x-\mu_t(x_1)\big) + \mu_t'(x_1) \]

不同的 \( (\mu_t,\sigma_t) \) 给出不同方法：

路径\( \mu_t,\ \sigma_t \)性质
扩散路径（VP）由 \( \bar\alpha_t \) 决定的 schedule回到 score/diffusion；轨迹弯曲，且 \( t\to 0 \) 只在极限意义上接近 \( \mathcal{N}(0,I) \)
OT / 线性路径\( \mu_t = t x_1,\ \sigma_t = 1-t \)条件轨迹是直线，端点严格是 \( \mathcal{N}(0,I) \) 与数据

线性路径下一切化简到近乎不可思议的地步：\( x_t = (1-t)x_0 + t x_1 \)，\( u_t = x_1 - x_0 \)，于是

Rectified Flow / OT-CFM 的完整损失
\[ \mathcal{L} = \mathbb{E}_{t\sim\mathcal{U}[0,1],\,x_0\sim\mathcal{N}(0,I),\,x_1\sim p_{\text{data}}}\Big\| v_\theta\big((1-t)x_0 + t x_1,\ t\big) - (x_1-x_0) \Big\|^2 \] 
# ---- 训练：比 DDPM 还短 ----
for x1 in dataloader:
    x0 = randn_like(x1)
    t  = rand(x1.shape[0])                    # t ~ U[0,1]，无需 α/β schedule
    xt = (1 - t) * x0 + t * x1                # 直线插值
    loss = mse(v_theta(xt, t), x1 - x0)       # 目标就是位移，常数向量

# ---- 采样：解 ODE，欧拉法即可 ----
x, dt = randn(shape), 1.0 / N
for i in range(N):
    x = x + v_theta(x, i * dt) * dt

5.5 为什么「直」这么值钱

欧拉法的局部误差正比于轨迹的曲率。路径越直，用大步长走完的代价越小：扩散路径要 50 步的地方，rectified flow 常常 10 步以内就够。进一步的拉直手段：

  • mini-batch OT 配对：不随机配 \( (x_0,x_1) \)，而在每个 batch 内解一个小型最优传输问题再配对，让条件直线之间少交叉，边缘场因此更直。
  • Reflow：用训好的模型生成配对 \( (x_0, \text{模型输出}) \)，再训一遍，把 ODE 拉到接近直线，逼近 1–4 步生成。这是 Rectified Flow 的招牌操作，下一节单独讲。
💡
额外的自由度

Flow Matching 不要求起点是高斯。\( p_0 \) 可以是任意能采样的分布——低清图、另一种模态、某个物理初态。这让它天然适合超分、图像翻译、蛋白结构等「分布到分布」的搬运任务，而扩散模型必须绕道噪声。工业界 Stable Diffusion 3、FLUX 等已经全面转向 rectified flow。

6. Rectified Flow：把「拉直」本身当成一个可迭代的操作

Liu, Gong & Liu 2022 · arXiv 2209.03003

6.1 它和 Flow Matching 到底什么关系

三篇同期独立工作——Rectified Flow（2022.09）、Flow Matching（2022.10）、Stochastic Interpolants（2023.03）——在训练损失上收敛到了同一个式子。区别在出发点，而出发点决定了各自多做了什么：

  • Flow Matching 从「CNF 怎样才能 simulation-free 地训」出发，先建一般框架（任意概率路径 + 条件化技巧），线性路径只是其中一个漂亮的特例。
  • Rectified Flow 从「两个分布之间最省事的搬运方式就是走直线」出发，一上来只研究线性插值，然后把重心放在一个 FM 没有的操作上：reflow（再校正）。
最短的关系式
\[ \text{线性路径的 Flow Matching}\ \equiv\ \text{1-Rectified Flow} \]
📌
命名坑

论文里跑一次 rectify 得到的流叫 1-rectified flow，拿它的输出再训一次叫 2-rectified flow，依此类推。而工业界（SD3、FLUX）说的 "rectified flow" 通常只指 1-rectified flow，也就是线性路径的 FM——它们并没有真的做 reflow。看到这个词先确认是哪一层含义。

6.3 关键认识：条件路径是直的，ODE 轨迹却是弯的

这一点极易混淆，但它是理解 reflow 存在意义的唯一前提：

  • 给定一对 \( (x_0,x_1) \)，条件路径是直线——按定义如此，没什么可讨论的。
  • 但网络学到的是边缘场：经过点 \( x \) 的所有条件直线的平均方向（§5.3 的图 6）。
  • 随机配对的条件直线在空间中会大量交叉。交叉处的平均方向，不等于任何一条原直线的方向。
  • 于是真实的 ODE 轨迹是弯的，哪怕每条条件路径都笔直。

6.4 Reflow：用模型自己的输出解开交叉

核心观察一句话：同一个 ODE 的两条轨迹永远不会相交（否则解不唯一）。所以如果不再随机配对，而是用已训好的模型真实走出来的配对 \( (x_0,\ \text{ODE}(x_0)) \)，这批配对天然不交叉，拿它重训，边缘场自然更直。

6.6 采样器：一个 for 循环，顺带再证一次「随机性可选」

7. Energy Matching：把向量场收回成一个标量势

Balcerak et al. · NeurIPS 2025 · arXiv 2504.10612

7.1 前面几种方法丢掉了什么

Diffusion 和 Flow Matching 学的都是向量场。而一般的向量场不是任何标量函数的梯度（有旋量），因此模型手里没有显式的 \( \log p(x) \) 或能量。这带来几个实际缺口：

  • 做逆问题（去模糊、CT 重建、缺失补全）时，想把「数据先验」作为一个能量项加进优化目标——没有能量就只能靠各种引导（guidance）近似替代。
  • 想把多个约束相加组合（能量可加，向量场不能随便加）。
  • 想拿未归一化的似然做比较或退火采样。

能量模型（EBM）本来就有这些能力，但训练出了名地难：需要长链 MCMC 采负样本，不稳定、易发散，生成质量一直落后扩散一大截。Energy Matching 的目标就是两头兼得。

7.2 核心设计：一个时间无关的标量场

它只学一个网络 \( V_\theta: \mathbb{R}^d \to \mathbb{R} \)，没有时间条件、没有辅助生成器、没有第二个网络——这与近年多数 EBM 方法的做法是明显分道。理论支架是 Wasserstein 空间中的 JKO 梯度流格式：

JKO 格式
\[ \rho_{k+1} = \arg\min_{\rho}\ \Big\{ \frac{W_2^2(\rho,\rho_k)}{2\Delta t} + \int V(x)\rho(x)\,\mathrm{d}x + \varepsilon(t)\int \rho(x)\log\rho(x)\,\mathrm{d}x \Big\} \]

关键在于让熵项系数 \( \varepsilon(t) \) 随时间变化，于是同一个 \( V_\theta \) 产生两个截然不同的阶段：

阶段条件动力学作用
传输相
远离数据流形		 \( \varepsilon(t)\approx 0 \) \( \dot{x} = -\nabla_x V_\theta(x) \) 无旋（curl-free）、近似最优传输的直线路径，把噪声搬到数据附近
平衡相
靠近数据流形		 \( \varepsilon(t)=\varepsilon_{\max} \) Langevin 动力学 落入玻尔兹曼平衡 \( \rho_{\text{eq}}(x)\propto e^{-V_\theta(x)/\varepsilon_{\max}} \)，显式刻画似然结构

7.3 训练目标：回归 + 对比散度

训练分两个阶段，损失是两项之和：

总损失
\[ \mathcal{L}(\theta) = \mathcal{L}_{\text{OT}} + \lambda_{\text{CD}}\,\mathcal{L}_{\text{CD}} \]

① 传输项（热身期单独训，之后保留）：在最优传输耦合 \( \pi_{\text{OT}} \) 下把 \( -\nabla V_\theta \) 回归到 rectified-flow 的位移目标

\[ \mathcal{L}_{\text{OT}} = \mathbb{E}_{t,\ (x_0,x_1)\sim\pi_{\text{OT}}}\Big\| \nabla_x V_\theta(x_t) + (x_1 - x_0) \Big\|^2 \]

② 对比散度项（主训练期加入）：压低真实数据的能量、抬高负样本的能量

\[ \mathcal{L}_{\text{CD}} = \mathbb{E}_{x\sim p_{\text{data}}}\Big[\frac{V_\theta(x)}{\varepsilon_{\max}}\Big] - \mathbb{E}_{x\sim p_{\text{neg}}}\Big[\frac{V_\theta(x)}{\varepsilon_{\max}}\Big] \]

负样本 \( p_{\text{neg}} \) 由 Langevin MCMC 产生，且同时从数据端和噪声端初始化——前者稳住局部盆地形状，后者防止能量在远处塌掉。注意第 ① 项的符号：因为速度场是 \( v=-\nabla V \)，回归目标写成 \( \nabla V \approx -(x_1-x_0) \)，等价于 \( v \approx x_1-x_0 \)，与第 6 节的 Rectified Flow 完全一致。Energy Matching 在传输段就是一个「被约束成梯度场」的 Flow Matching。

Meta 的库把「路径」抽象成 ProbPath。核心两行在 AffineProbPath.sample 里：

9.3 两者是同一个模板——库里直接写着换算函数

这是最能说明「异同」的一处代码。AffineProbPath 提供了 6 个方法，把 \( \varepsilon \) / \( x_1 \) / \( v \) 三种预测目标互相换算，比如：

facebookresearch/flow_matching · flow_matching/path/affine.py:120-144 
def epsilon_to_velocity(self, epsilon, x_t, t):
    a_t = d_alpha_t / alpha_t
    b_t = (d_sigma_t * alpha_t - d_alpha_t * sigma_t) / alpha_t
    return a_t * x_t + b_t * epsilon

全是 x_t 与目标的线性组合，系数只依赖 schedule。把 DDPM 的 \( \alpha_t=\sqrt{\bar\alpha_t},\ \sigma_t=\sqrt{1-\bar\alpha_t} \) 代进去，它就落在同一个 AffineProbPath 家族里。

🔑
「DDPM 和 Flow Matching 到底差在哪」的最短回答

差在 schedule 的选择和回归目标的记号，不差在框架。同一个 \( x_t=\alpha_t x_1+\sigma_t x_0 \) 模板：DDPM 选带噪扩散那组 \( (\alpha,\sigma) \) 并回归 \( \varepsilon \)；FM 选 \( (t,1-t) \) 并回归 \( v \)。两者之间隔着上面那个可逆线性变换——库里把它当工具函数提供，就是承认了这一点。

9.4 采样器：DDPM 和 DDIM 在同一个函数里

9.5 Energy Matching：velocity 是 potential 的自动微分

这是几种方法里唯一一处结构性的不同，而且代码写得极其直白：

m1balcerak/EnergyMatching · experiments/cifar10/network_transformer_vit.py:177-223 
def potential(self, x, t):
    t_dummy = dummy_time(x, value=0.5)      # ← 时间被忽略，永远喂 0.5
    unet_out = super().forward(t_dummy, x)
    tokens   = self.patch_embed(unet_out)
    pooled   = self.transformer_encoder(tokens).mean(dim=1)
    V = self.final_linear(pooled).view(-1) * self.output_scale
    return V                                # (B,) 一个标量

def velocity(self, x, t):
    with torch.enable_grad():
        x = x.clone().detach().requires_grad_(True)
        V = self.potential(x, t)
        dVdx = torch.autograd.grad(V, x, grad_outputs=torch.ones_like(V),
                                   create_graph=True)[0]
        return -dVdx                        # v = −∇V

def forward(self, t, x, return_potential=False, *args, **kwargs):
    return self.potential(x, t) if return_potential else self.velocity(x, t)

def plot_epsilon(t, at_data=False):
    if   t < cutoff: return 0.0                                  # 传输相：g=0，退化成纯 ODE
    elif t < 1.0:    return (t - cutoff)/(1.0 - cutoff) * eps_max  # 过渡：噪声线性升起
    else:            return eps_max                              # 平衡相：满噪 Langevin

def g(self, t, y):                 # torchsde 的扩散项
    e_val = plot_epsilon(float(t))
    if e_val <= 0: return torch.zeros_like(y)
    return torch.sqrt(2.0 * e_val).expand_as(y)

10. 条件怎么注入

这是与前面几种方法正交的一个维度：条件注入机制基本不关心你用的是扩散还是流匹配，同一套写法可以直接搬。总共就三种机制（前两种可叠加），外加 Energy Matching 独有的第四种。

10.1 机制一：条件 → 一个向量 → 调制归一化层

最常见的一种，而且有个容易被忽略的事实：类别条件走的是和时间 t 完全相同的通道。

📌
为什么加条件几乎不用改架构

因为网络本来就已经在被一个标量（时间）调制了。c = t + y 这一行的意思是：类别只是往同一个插座里又插了一个向量。想加第三个条件（比如美学分数、分辨率），继续 c = t + y + s 即可——SDXL 的 size/crop conditioning 正是这么做的。

10.2 机制二：变长条件走 cross-attention

文本 prompt 这类压不进单个向量的条件，编码成 token 序列 \( c_{1..L} \)，在 block 里加一层交叉注意力：Q 来自图像 token，K/V 来自条件 token。Stable Diffusion 的文本通路即是如此。它与机制一叠加使用而非替代——时间仍走 FiLM/adaLN，文本走 cross-attn。上面两个仓库的图像示例都是类别条件，所以只用了机制一。

10.3 机制三：Classifier-Free Guidance

前两种机制只负责「把条件送进去」。要让条件足够强，还得靠 CFG。它分训练、推理两半。

先说清 CFG 在做什么，空条件的位置才好理解

条件生成要的分数，可以按贝叶斯拆成两块：

\[ \underbrace{\nabla_x\log p(x\mid y)}_{\text{条件分数}} = \underbrace{\nabla_x\log p(x)}_{\text{无条件分数}} + \underbrace{\nabla_x\log p(y\mid x)}_{\text{「更像 }y\text{」的方向}} \]

第二项是「隐式分类器」的梯度——它指向更符合条件的方向。CFG 的想法就是把这一项放大 \( s \) 倍（贴合条件更紧，代价是多样性下降）：

\[ \begin{aligned} \tilde{\nabla} \;&=\; \nabla_x\log p(x) \;+\; s\cdot\nabla_x\log p(y\mid x) \\[8pt] &=\; \nabla_x\log p(x) \;+\; s\cdot\Big[\underbrace{\nabla_x\log p(x\mid y)}_{\text{条件那一支}} \;-\; \underbrace{\nabla_x\log p(x)}_{\text{无条件那一支}}\Big] \end{aligned} \]

对应采样的分布是 \( p(x)\,p(y|x)^{s} \propto p(x|y)\,p(y|x)^{s-1} \)，也就是把条件后验锐化。

盯住最后一行：要算出这个式子，必须同时拿到 \( \nabla\log p(x\mid y) \) 和 \( \nabla\log p(x) \)。前者是条件模型，后者就是无条件模型——而一个从头到尾只见过带标签样本的网络，是给不出后者的。

🔑
空条件的作用：它是减法的基准点

空条件不是占位符。CFG 的核心是一个减法，减法就需要一个基准；这个基准正是「什么条件都没给」时网络的预测。训练时按概率把条件替换成 null，就是在用同一套权重额外训练出无条件那一支，好让推理时减得出来。没有它，CFG 的括号里只有一项，整个方法不成立。

由此有三个推论，都很实用：

  • 「Classifier-Free」的 free 指的就是这件事。更早的 classifier guidance（Dhariwal & Nichol）要单独训一个分类器 \( p(y|x_t) \) 来提供 \( \nabla\log p(y|x) \)——而且得能在各个噪声水平上工作，又贵又容易被对抗梯度骗。CFG 用一行 label dropout 把无条件模型免费塞进同一个网络，隐式分类器由两支相减自动得到，根本不用真的训分类器。
  • null 必须是网络见过的、有含义的输入。DiT 给它一行专属的可学习 embedding（索引 = num_classes）；flow_matching 把 dict 清空后由 UNet 填 padding index。不能随手喂零向量或噪声——那是网络没训过的输入，输出没有意义，减出来的方向自然也没有意义。
  • dropout 比例是个权衡。太低，无条件那支学不好、基准点不准；太高，又挤占了条件建模本身的训练量。常用 10%（DiT 的 --class-dropout-prob 0.1）。

DiT 的做法是在 embedding 表里多留一行当 null token：

DiT 的 uncond + s·(cond − uncond) 展开是 \( s\cdot\text{cond} + (1-s)\cdot\text{uncond} \)；flow_matching 的 (1+w)·cond − w·uncond 要令 \( s = 1+w \) 才等价。DiT 里 s=1 表示「无引导」，flow_matching 里 w=0 才表示「无引导」。跨仓库搬 guidance scale 时这是最常踩的坑（DiT 常用 s=1.5，对应 flow_matching 的 w=0.5）。

📌
为什么 CFG 能直接搬到 Flow Matching 上

CFG 原本是从分数推出来的（\( \nabla\log p(x|y) \) 的外推）。但由 §9.3 那组换算函数，速度场与分数之间是仿射关系，对两支输出做同样的线性外推，等价于对分数做外推。所以公式一个字不用改——这正是 flow_matching 库敢直接对 velocity 做 CFG 的依据。

💡
顺带解释了 negative prompt

既然无条件那一支的角色只是减法的基准点，那把它换成「别的条件」会怎样？

\[ \tilde{\varepsilon} = \varepsilon(x, y_{\text{neg}}) + s\cdot\big[\varepsilon(x, y_{\text{pos}}) - \varepsilon(x, y_{\text{neg}})\big] \]

外推方向从「无条件 → 条件」变成「\( y_{\text{neg}} \) → \( y_{\text{pos}} \)」，样本于是被推离 \( y_{\text{neg}} \)。这就是 Stable Diffusion 里 negative prompt 的全部原理——它没有新增任何机制，只是把 CFG 空条件那一支替换成了你想远离的东西。空字符串 "" 只是它的默认取值。

⚠️
基准点太差会带偏方向

无条件那一支的绝对质量不重要（它只提供参考方向），但它在某些时刻可能很不可靠——尤其 \( t \) 极大或极小时两支几乎重合，相减放大的主要是噪声。实践中的对策是只在一段时间区间里开 CFG，区间外把 scale 置回 1.0。JiT 的实现就是这么做的，见 §11.5。

10.4 机制四：Energy Matching 把条件加成能量项

这里才出现真正的机制差异。因为模型输出是标量，条件不必进网络——采样时把额外能量项加到 \( V \) 上，再求一次梯度就行。论文的蛋白质实验就是这么做后验采样的：

m1balcerak/EnergyMatching · experiments/proteins/sampling.py:112-132 
x.requires_grad_(True)
v = model.potential(x, t_val.unsqueeze(0)).sum()               # 学到的数据能量

# ① 观测似然 → 能量项（classifier guidance 的能量写法）
y_pred = (pred.forward_soft(vae_model.decode(x.squeeze())) - y_min) / (y_max - y_min)
likelihood = 0.5 * ((y_pred - y_gt.squeeze()) ** 2)

# ② 样本之间的排斥 → 能量项（鼓励多样性）

W = 0.5 * diffs[mask].sum() * (e_t / sigma_W**2)

grad_x = torch.autograd.grad(u, x)[0]

with torch.no_grad():
    x = (x - dt_t * grad_x + sigma * noise).clamp(-1, 1)        # 一次 Langevin 更新

u = v + cg - W 这一行就是全部。对比一下两种路线的代价：

维度CFG（扩散 / FM）能量相加（EM）
要不要改训练要：训练期按概率丢条件不要，采样期临时加
每步 NFE2×1× ＋ 条件项自身的梯度
加第二个条件需重新设计（多条件权重难调）再加一项：u = v + c₁ + c₂
条件的形式要求要么编进网络，要么单独训 classifier只要对 x 可微即可
跨样本约束写不出来（每个样本速度独立算）可以：上面的排斥项 W
条件强度可控性成熟、经验丰富要调温度 \( \varepsilon \) 与各项系数，更敏感

特别注意②那个排斥项：它是 batch 内样本两两之间的相互作用能，让同一批样本互相推开以提升多样性。这种跨样本约束在纯向量场模型里根本没有对应写法，因为那里每个样本的速度是各算各的。

🔑
条件注入的一句话总结

扩散 / Flow Matching 的条件必须在训练期编进网络（然后靠 CFG 在推理期放大）；Energy Matching 的条件可以在采样期以能量项的形式任意叠加，不动模型。这就是论文说的「EBM 的灵活性」在代码里的确切含义。代价是采样端要跑 Langevin，且多了一组温度超参要调。

⚠️
一个诚实的限定

EnergyMatching 仓库的 CIFAR-10 / ImageNet 实验是无条件生成（class_cond=False），机制四的完整演示只在蛋白质实验里。所以「EM 的类别条件图像生成效果如何」这个问题，目前还没有公开数据可比——上表比的是机制的性质，不是已验证的图像生成效果。

11. 另一条正交轴：U-Net → DiT → JiT

11.2 DiT：把骨干换成 Transformer，顺便证明 scaling law 成立

DiT（Peebles & Xie, ICCV 2023）的三件事：

  • 扔掉 U-Net 的卷积 + 跳连结构，改成在 VAE latent 的 patch 上跑标准 Transformer；
  • 条件（\( t \) 与 \( y \)）用 adaLN-Zero 注入——§10.1 已经逐行读过；
  • 核心结论：FID 随模型 Gflops 单调下降。也就是说 scaling law 在扩散骨干上同样成立。这才是它真正的贡献，也是后来 SD3 / FLUX / Sora 全线转向 Transformer 的依据。

11.3 JiT：把「预测什么」这个问题问到底

Li & He 2025 · arXiv 2511.13720 · Just image Transformers

挑衅就写在标题里——《Back to Basics: Let Denoising Generative Models Denoise》：现在的「去噪」模型其实都不预测干净图像，它们预测的是噪声 \( \varepsilon \) 或速度 \( v \)。JiT 主张直接预测 \( x \)，并且扔掉 tokenizer、latent 空间和 U-Net，让一个朴素 ViT 直接吃原始像素 patch。

训练代码把这个差别摆得极其清楚：

LTH14/JiT · denoiser.py:52-64 
t = self.sample_t(x.size(0), device=x.device).view(-1, *([1] * (x.ndim - 1)))
e = torch.randn_like(x) * self.noise_scale

z = t * x + (1 - t) * e                           # ① 线性路径，与 §6.2 的 rectified flow 同款
v = (x - z) / (1 - t).clamp_min(self.t_eps)       #    目标速度

x_pred = self.net(z, t.flatten(), labels_dropped) # ② ★ 网络输出的是 x（干净图）
v_pred = (x_pred - z) / (1 - t).clamp_min(self.t_eps)

loss = (v - v_pred) ** 2                          # ③ 但损失仍在 v 空间算
loss = loss.mean(dim=(1, 2, 3)).mean()

三处标注对应三件独立的事：①路径是 Flow Matching 的（JiT 不是新的建模范式）；②网络的输出口开在 x 上；③损失仍在 v 空间，两者之间由 §9.3 那个线性关系连接。

11.4 为什么「线性重参数化」在这里不再无害

§12 的要点框会说：\( \varepsilon \) / \( x_0 \) / \( v \) 互为线性重参数化，不是不同范式。JiT 恰好是这句话的边界案例，值得说清楚。

换算确实是线性的，但看系数——是 \( \tfrac{1}{1-t} \)，在 \( t\to 1 \)（接近干净数据）时会爆炸。于是同一份误差，经过不同输出口进入损失时被放大的程度完全不同：

  • 网络输出 x：\( x \) 的误差被 \( \tfrac{1}{1-t} \) 放大后进损失——但 \( x \) 本身好学。
  • 网络输出 ε 或 v：数据端误差被压缩，噪声端误差被放大——而噪声那一端并不好学。

在低维 latent 上（DiT 的一个 patch 只有几十维）这点差别不致命。但 JiT 直接跑像素：patch 16 意味着每个 token 是 \( 16\times16\times3=768 \) 维，patch 32 则是 3072 维。论文报告，在这种维度下预测「加噪后的量」会灾难性失败，而预测 \( x \) 不会。

📌
解释指向流形假设

干净图像 \( x \) 位于高维像素空间中的一个低维流形上，网络容易拟合。而 \( \varepsilon \) 是各向同性高斯噪声，\( v \) 含有它的成分——它们不在任何低维流形上。逼一个容量有限的网络去精确回归一个高维满秩的随机量，本身就是个坏任务。

这个假设还被直接写进了架构。JiT 的 patch embedding 不是一步到 hidden，而是先过一个瓶颈：

LTH14/JiT · model_jit.py:29-30（BottleneckPatchEmbed） 
# patch(3072 维) → pca_dim 瓶颈(128) → hidden
self.proj1 = nn.Conv2d(in_chans, pca_dim,
                       kernel_size=patch_size, stride=patch_size, bias=False)
self.proj2 = nn.Conv2d(pca_dim, embed_dim,
                       kernel_size=1, stride=1, bias=bias)

参数名叫 pca_dim，默认 128。也就是说 3072 维的原始 patch，先被一个无 bias 的线性层压到 128 维再升到 hidden。「数据在低维流形上」这句话被翻译成了一个 Conv2d。

11.5 JiT 顺带印证了本文前面的两个说法

其一，\( t \) 确实不是均匀采的（§6.6 那个 note）：

LTH14/JiT · denoiser.py:45-47 
def sample_t(self, n: int, device=None):
    z = torch.randn(n, device=device) * self.P_std + self.P_mean
    return torch.sigmoid(z)        # logit-normal，与 SD3 同一个选择

其二，CFG 用的是 DiT 那个「s=1 表示不引导」的约定（§10.3 那个差 1 的坑），而且多了一个实用技巧——CFG 只在一段时间区间内开：

LTH14/JiT · denoiser.py:98-104 
low, high = self.cfg_interval
interval_mask = (t < high) & ((low == 0) | (t > low))
cfg_scale_interval = torch.where(interval_mask, self.cfg_scale, 1.0)   # 区间外置 1.0 ＝ 不引导

return v_uncond + cfg_scale_interval * (v_cond - v_uncond)

区间外把 scale 置成 1.0 而不是 0.0——这一行本身就再次确认了该约定下 s=1 才是「无引导」。

11.6 JiT 的条件注入：两条路一起走

§10 列了四条通路，JiT 里能看到第一条和一个自注意力变体的组合：

LTH14/JiT · model_jit.py:337-354 
t_emb = self.t_embedder(t)
y_emb = self.y_embedder(y)
c = t_emb + y_emb                      # ① 与 DiT 完全一样：合成一个向量走 adaLN

for i, block in enumerate(self.blocks):
    if self.in_context_len > 0 and i == self.in_context_start:
        in_context_tokens = y_emb.unsqueeze(1).repeat(1, self.in_context_len, 1)
        in_context_tokens += self.in_context_posemb
        x = torch.cat([in_context_tokens, x], dim=1)   # ② 类别再变成 32 个 token 拼进序列
    x = block(x, c, ...)

x = x[:, self.in_context_len:]         # 输出时把这些 token 丢掉

同一个类别条件走了两条路：既调制每个 block 的 adaLN，又从第 8 层起以 32 个「in-context token」的身份参与自注意力。后者是 §10.2 那个 cross-attention 思路的自注意力版本——不额外加一层 cross-attn，直接把条件拼进序列，让原有的自注意力去处理。

13. 怎么选，以及这条脉络说明了什么

13.1 选型

  • 要成熟生态、大量预训练权重与社区工具 → 扩散模型 + DDIM / DPM-Solver 采样器。
  • 要少步、要训练简洁、要在两个非高斯分布之间搬运（超分、翻译、跨模态） → Flow Matching / Rectified Flow。今天从零开搞的新项目，这通常是默认选择。
  • 要密度、要把物理约束或观测作为能量项加进去、要做逆问题正则或多约束组合 → Energy Matching 及 EBM 路线，接受更慢的采样。
  • 要极致实时（单步 / 少步） → 在 Flow Matching 基础上叠 Reflow + 蒸馏（第 6 节，代价是一轮全量 ODE 推理造数据），或换 consistency models / 对抗蒸馏。

13.2 一条脉络

把这几步连起来看，每一步都是在拆掉上一步中一个「其实不必要」的约束——画成台阶就很清楚：

  1. DDPM：把生成变成对已知加噪过程的回归——可训练了。
  2. DDIM：发现训练只锁住边缘分布——采样与训练解绑，随机性成为可选项。
  3. SDE / 概率流 ODE：说明「加噪路径」也只是众多选择之一——路径自由。
  4. Flow Matching：那就选最直的路，目标简化成回归位移——步数塌缩，且起点不必是高斯。
  5. Rectified Flow：再发现「直」本身可以被反复校正，燃料是模型自己的输出——步数塌到个位数。
  6. Energy Matching：再把向量场约束成某个标量的梯度——拿回密度与可组合性，代价是采样端重新引入 MCMC。
每一次进展都不是加了什么新组件，而是发现某个被默认接受的结构其实是可拆的。
